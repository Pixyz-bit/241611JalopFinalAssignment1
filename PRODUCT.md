# C# Programming Showcase

## Purpose and audience
A student programming showcase for visitors and assignment reviewers. The owner supplies the actual example titles, explanations, forms, algorithms, and CRUD logic later.

## Platform and stack
ASP.NET Core MVC targeting .NET 8. Razor, plain CSS and JavaScript; no React, Node build pipeline, database or authentication for this template.

## Confirmed requirements
- Title: C# Programming Showcase.
- Input/Output, Conditional, Repetition, Basic CRUD; five empty example slots each.
- macOS-inspired blue mountain desktop, dimensional folders, translucent menu and dock.
- One Finder-style window with category sidebar, example list and detail area.
- Functional canonical URLs without JavaScript; enhanced browser navigation.
- Mobile, keyboard, visible focus and reduced-motion support.

## Scope
UI, shared templates, navigation and honest unimplemented states. The owner authors the examples; never simulate working execution or persistent CRUD.

## Repository layout
Solution root: AGENTS.md, PRODUCT.md, DESIGN.md and README.md. Detailed notes: docs/. Project skill: .agents/skills/showcase-ui/. App: 241611JalopFinalAssignment1/ with standard Controllers, Models, Views and wwwroot folders. Installed design skills stay in their global folders.
