# Surface brief

## Confirmed direction
The user supplied a macOS-style portfolio desktop as visual authority and approved a blue mountain desktop for C# Programming Showcase, using one Finder-style window with category sidebar and five examples. The existing project is ASP.NET Core MVC, net8.0. Build directly in Razor/CSS/JavaScript; no generated interface comp is needed for this task-oriented template.

## Direction contract
- **Thesis:** explore four C# concepts as folders on a familiar desktop.
- **Own world:** blue hour mountain photography, blue folder silhouettes, translucent desktop chrome, light precise Finder surfaces and Geist typography.
- **Story:** home desktop → category overview → one of five clearly unimplemented example templates. Keep ordinary browser navigation throughout.
- **First viewport:** four labeled folders, C# Programming Showcase welcome, menu/navigation/search and a bottom dock. No portfolio-specific identity or irrelevant system icons.
- **Form:** one Finder window, category sidebar, five entries, description/interface/output detail. On mobile, categories and examples become horizontal navigation above the content.
- **Signature interaction:** opening a folder brings one window forward; minimize returns to the desktop and the active dock icon restores that same example.

## Modes
Desktop: Experience. Finder and search: Operate. Explanatory About content: Read. Mode-specific defaults never override the approved desktop metaphor.

The review directory is .impeccable/review/. Required captures: desktop home, desktop Finder/example, mobile home, mobile example and search.
