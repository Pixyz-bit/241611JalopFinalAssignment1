# Surface brief — Windows branch

The approved Windows 11 inspired desktop presents four C# categories with five implemented examples each. Preserve ASP.NET Core MVC, net8.0, Razor, CSS and plain JavaScript. The Windows direction lives on windows-design; main retains the earlier macOS version.

Visitors open a category directly into Example 1 and use five named sidebar links. The user-supplied wallpaper, transparent PNG concept icons, Geist typography, pale taskbar glass and light application window form the shared system. Desktop credits replace the welcome block. About and category overview screens are retired.

Canonical links and native forms work without JavaScript. Enhancement adds cached navigation, history, exact-example minimize/restore and Ctrl/Cmd+K search. Start contains category links and an accessible desktop action. Maximize reserves the taskbar.

[DESIGN.md](../DESIGN.md) defines current layout and accessibility. [architecture.md](architecture.md) maps decisions to code. [validation.md](validation.md) preserves dated evidence and limitations; older screenshots document earlier stages, not current verification.
