## Verified findings

### P2: Active taskbar shortcut changes the selected example

Location: `wwwroot/js/site.js:175`.

Open Input/Output Example 2, calculate a result, then click Input/Output in the taskbar while the window is visible. The URL and content change to Example 1. The same shortcut correctly restores Example 2 when minimized. The restore branch requires `minimized`, and the remaining path navigates to the category's Example 1 URL. This contradicts DESIGN.md's active-category restore behavior and interrupts the current task. Handle active taskbar category selection before navigating; cover both visible and minimized states in navigation tests.

### P2: Temperature Swap can produce an input the server rejects

Locations: `Models/InputOutput/JALOPARLANMARTIN_241611_TemperatureConverterViewModel.cs:11`, `Controllers/JALOPARLANMARTIN_241611_InputOutputController.cs:72–79`.

Convert 1,000,000 Celsius to Fahrenheit, then Swap. The new input is 1,800,032 Fahrenheit. Confirm rejects it because every source scale shares a maximum of 1,000,000. Native Swap reproduces the same inconsistency. Align the supported domain with converted output, or give explicit feedback before producing an unusable swapped input. Preserve absolute-zero validation. `node docs/review/edge-probes.cjs` reproduces this finding.
